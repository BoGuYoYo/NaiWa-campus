# 奈珑 · 特殊剧情表情立绘（场景对照 + 生图提示词）

> 现状：`assets/portraits/xiaoyou/` 下的 `neutral / happy / sad / surprised` **四张是同一个文件**
> （MD5 全是 `37134788…`），等于"有四个表情位、只有一个表情"。
> `sad` 这张在全部剧情里一次都没用到，而关系线里最需要"害羞"的两句被塞给了 `surprised`。

---

## 1. 她在剧情里出场的每一页

| # | 事件 | 台词 | 现在用的 | 应该用 |
| --- | --- | --- | --- | --- |
| 1 | 关系第 1 段 · 速写本 | 「这、这张还没画完……不过，你可以看。」 | `surprised` | **`shy`（脸红+视线躲开）** |
| 2 | 关系第 2 段 · 双人通关 | 「通关了！……和你一起，好像没那么难。」 | `surprised` | **`happy`**（眼睛发亮，笑到一半） |
| 3 | 关系第 3 段 · 同一张画布 | 「原来合作是这个感觉。像有人陪着一起做梦。」 | `happy` | `happy`（柔一点的版本） |
| 4 | 开学招新（S1） | 「要不要一起去逛展？」 | `surprised` | **`shy`**（抱着海报、小声） |
| 5 | 校园创作征集（S3） | 「如果你愿意，我想和你一起把它完成。」 | `neutral` | `neutral`（眼神发亮，不是面瘫） |
| 6 | 大四项目（S7） | 「Game Jam 结束后，我有句话想告诉你。」 | `neutral` | **`shy`** 或 `neutral`（郑重+脸红） |

结论：**必须有 `neutral / happy / shy / surprised` 四张**，`sad` 可选（留给失败/低落剧情）。

如果要连"郑重、期待"也分开，再加一张 `expectant`（可选）。

## 2. 角色基准（三张图都要一致）

| 项 | 设定 |
| --- | --- |
| 发型 | 金色双马尾，齐刘海，发尾微卷；马尾用**绿色发带**扎 |
| 眼睛 | 绿色（#4F8A5B ~ #8FC08A 之间），大眼，睫毛深色 |
| 服装 | 奶黄色开衫（#F7C81E / #FFDD5C 亮面）+ 白色圆领衬衫（#F2F2F2）+ 领口**绿色蝴蝶结**（#4F8A5B） |
| 下装 | 深色百褶裙（#353320 / #4C4A2F） |
| 构图 | **胸像（头到胸口）**，正面略微 3/4 侧，肩膀左右留空，头顶留 4~6 px |
| 尺寸 | 生成 1024×1024，最终 **96×96** |
| 背景 | **纯灰 #808080 平涂**（不要棋盘格、不要白底）——导入工具是按灰底洪水填充抠图的 |
| 调色 | 32 色（沿用 `assets/palette.png`），硬边像素，无描边（或极细深色描边） |
| 文字 | 画面里不许出现文字 |

```
像素风游戏角色半身立绘，胸前裁切，正面略 3/4 侧，1024×1024，人物居中、头顶留一点空；
硬边像素、无抗锯齿、无渐变，只用 32 色调色板；背景纯灰 #808080，画面里没有任何文字。
角色：金发双马尾（绿色发带）、绿眼睛、奶黄色开衫 + 白色圆领衬衫 + 领口绿色蝴蝶结、深色百褶裙。
表情：平静自然，眼睛睁开、视线看向正前方偏一点，嘴唇轻闭微微上扬一点点；
双手不在画面里，肩膀放松。整体是"安静但亲和"的日常脸。
```

**要点**：不要笑得太开，也不要面瘫；眼眶有高光但只有一两粒像素。

像素风游戏角色半身立绘，胸前裁切，正面略 3/4 侧，1024×1024，人物居中、头顶留一点空；

## 6. 图到了怎么接（A 侧）

1. 放 `assets/portraits/xiaoyou/<表情>.png`（96×96，透明底）；
2. manifest 补 `portrait_npc_xiaoyou_shy`（新 id 才需要），`sad` 已经登记但没被引用；
3. `content/text/zh_CN/dialogues.json` 三处换 id：
   - `evt.rel_npc_xiaoyou_1.body.3`：`surprised` → **`shy`**
   - `evt.sem_1_club_fair.body.4`：`surprised` → **`shy`**
   - `evt.sem_7_final_project.body.2`：`neutral` → **`shy`**
4. `portrait_npc_xiaoyou_shy` 缺失时 `resolve_portrait` 会回退 `neutral`，不会崩；
   所以要"先接图、再改文本"，顺序反了也不会白屏。

## 7. 自查

1. 四张放在一起，**脸型、发型、服装、配色完全一致**，只有表情和姿态不同；
2. 背景是纯 #808080（导入工具靠这个抠，棋盘格会多抠三轮）；
3. 96×96 缩完五官还认得出：眼睛至少 3~4 px、瞳孔有 1 px 高光；
4. 没有文字、没有手势乱入、没有第二个人；
5. 腮红只用 #E091B0 与 #FFFBEE，别用纯红。
