# 室内家具与装修 · AI 生图提示词（5 栋建筑 · 正面 + 轻俯角）

> 视角约定：**正面为主、带约 20° 轻俯角**——看得到正面全貌，也能看到一条薄薄的顶面
> （桌面、柜顶、床面），但**不画侧面**。
> 依据：游戏里家具和树/路灯/建筑一样是"立在地上的一张卡"（`make_prop_card`，按 −40°
> 俯仰正对相机）。纯正面会显得纸片，3/4 斜视又会和相机打架，轻俯角正好。
> **地板**是唯一的例外：正俯视四方连续贴图。

---

## 0. 全局规格

| 项 | 规定 |
| --- | --- |
| 像素密度 | **24 px = 1 米** |
| 视角 | **正面 + 约 20° 俯角**：正面透视为零，顶面按 sin20°≈0.34 压成一条薄面；**不画侧面/侧壁** |
| 画布 | 宽 = 占地宽度 × 24；高 = （实物高 + 0.34 × 可视进深）× 24，逐件已算好，见 §4 |
| 底边 | 物体（含薄顶面）底边贴齐画布底部，左右居中，画布外全透明 |
| 调色板 | 只用 `assets/palette.png` 的 32 色 |
| 描边 | 不描边（描边只给角色/NPC），靠 3 级明暗分层 |
| 光影 | 光源在**左上方**；顶面比正面亮一档，正面右侧压暗 |
| 背景 | 全透明 RGBA，透明像素 RGB 为 0 |
| 生成方式 | 先按 4× 尺寸生成（如 96×60 → 384×240），再最近邻缩到目标尺寸 |
| 文字 | 不许出现任何文字/字母/数字 |

## 5. 交付与落位

| 类别 | 数量 | 命名 | 尺寸 |
| --- | --- | --- | --- |
| 地板 | 5 | `assets/interior/<building>/floor.png` | 64×64 无缝（正俯视） |
| 墙面 | 5 | `assets/interior/<building>/wall.png` | 64×72 无缝（纯正面） |
| 家具 | 17 | `assets/interior/<building>/furn_<id>.png` | 见 §4 |

`<building>`：`dorm / classroom / library / clubroom / canteen`；`<id>` 取 `map.json` 的 `furniture[].id` 去掉 `furn_` 前缀。

**渲染侧怎么用**：`make_prop_card(rect, texture, height)` 里
`卡片宽度 = height × 画布宽/高`。§4 的画布比例 = `占地宽 : (实物高 + 0.34×可视进深)`，
所以调用时 `height` 要传**画布高 / 24**（含那条顶面），卡片才正好占满占地宽度。

**交付前自查**

1. 四角 alpha = 0，无白底/棋盘格残留；
2. 颜色 ≤ 32 且都在 §0.1 色板内；
3. 画布尺寸与 §4 一致，底边贴齐画布底部；
4. 是「正面 + 一条薄顶面」——**看得到顶面、看不到侧面**；地板与挂墙件除外；
5. 画面里没有任何可读文字；
6. 文件名全小写、与表一致。

   （`interior_<building>_floor`、`_wall`、`furn_<building>_<id>`）。

3. 碰撞仍用 `map.json` 的 rect，不改玩法。
