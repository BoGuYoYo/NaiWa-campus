# 五个结局 CG · AI 生图提示词

> 结局页当前的排版（`game/ui/graduation_scene.py` 第 3 页）只有标题 + 三行正文，
> 没有插图位。要挂 CG 的话按这份文档出图即可：
> **整页 480×270**，下半部留一条暗色带压字，CG 主体放在上半部。

---

## 0. 全局规格

| 项 | 规定 |
| --- | --- |
| 画布 | **480 × 270**（与游戏内部画布同尺寸，1:1 铺满，不做缩放） |
| 可见主体区 | 上方 480 × 190；下方 480 × 80 留暗带（正文压在这里） |
| 输出格式 | **PNG**（不透明底，CG 不需要透明背景） |
| 像素密度 | 画面按"像素插画"而非 24 px/m 场景比例；关键物件大小要能一眼认出 |
| 调色板 | 只用 `assets/palette.png` 的 32 色 |
| 描边 | 角色可加 1~2 px 深色描边（和立绘一致），场景物件不描边 |
| 光影 | 光源在左上；夜晚场景允许改为屏幕光 / 路灯为主光，但仍只用色板里的颜色 |
| 文字 | **画面里不许出现任何文字**：通知、Offer、屏幕代码、成绩单一律画成色块或图标 |
| 生成方式 | 先按 4× 生成（1920×1080），再最近邻缩到 480×270 |

```

### 0.2 通用前缀

```
像素风游戏结局插画（ending CG），16:9 横构图，480×270 的像素画放大版：
正交视角、无快门透视，硬边像素、无抗锯齿、无渐变噪点；
只用给定 32 色调色板，光源统一在左上；角色是像素小人（两三头身，和游戏立绘同款比例），
角色可带 1~2 px 深色描边，场景物件不描边；画面里没有任何文字、字母、数字。
```

### 0.3 通用负面

```
3D 渲染, 写实照片, 景深, 泛光, 涂鸦笔刷, 抗锯齿, 渐变, 手写文字, 中文字, 字母, 数字, 水印, 签名,
logo, UI 界面, 对话框, 对话框气泡, 头像框, 字幕条, 过饱和, 彩虹色, 复杂花纹
```

## 1. 延毕结局｜大五学长的留级物语

**正文**：别人都在忙着告别青春，只有你获得了一年加长版体验卡。/ 教务系统亮起红色学分预警，
你需要在大五重新补齐毕业要求。/ 自由是有代价的：多交一年住宿费，还得听那句尴尬的"叫学长就好"。

**画面**：傍晚的空宿舍，别人的床位已经搬空（只剩床板与卷起的铺盖），奶娃一个人坐在行李箱上，
手里捏着一张纸（画成白纸 + 红色感叹号色块，不写字）；窗外是校园的黄昏，桌上摊着课程表（纯色格）。

```
像素风游戏结局插画，16:9 横构图：傍晚的空宿舍，同寝室三张床已经搬空、只剩床板和卷起的铺盖，
主角奶娃（黄发、浅黄上衣）一个人坐在行李箱上，手里捏着一张白纸，纸上只有一个红色感叹号色块；
桌上一张纯色格的课程表，窗外是橙紫色黄昏和几栋教学楼剪影；
画面右侧留出天空与窗框的空白，主体在下半部中间偏左，顶部 1/4 不要放重要元素。
配色压暗、以 #2C3446 #3A4458 #4A505C 为主，只用 #F7C81E #E28B3A 点亮窗光与那张纸；
情绪是"有点惨但还算豁达"，不要哭丧。
硬边像素、无抗锯齿、无渐变；只用 32 色调色板；画面里没有任何文字、字母、数字。
```

**不要**：撕碎的通知书、哭泣、老师训话、红色大字。

## 4. 坠入爱河｜通关后的双人存档

**正文**：你和奈珑从同好会的偶遇走到了 Game Jam 的领奖台下。/ 画画、联机和无数个并排熬夜的
夜晚，最后都写进了同一份存档。/ 大学这局游戏通关了，但属于你们的双人联机才刚刚开始。

> ⚠️ 这一张要的是**"已经在谈恋爱"的状态**，不是刚表白/刚领奖的那一瞬间：
> 两个人已经习惯了彼此的位置——并肩、牵手、各忙各的但挨在一起。

中下部；奈珑另一只手抱着速写本，奶娃另一只手拎着画袋；路灯刚亮，影子被拉得很长；
远处是教学楼的窗灯和一棵树。

```
像素风游戏结局插画，16:9 横构图：黄昏的校园主路，两个人并排往前走，背对镜头略侧身，

## 6. 接进游戏要做什么（A 侧，图到了我来）

1. 文件放 `assets/cg/ending_<id>.png`（480×270），manifest 登记 `cg_ending_<id>`，
   许可走 `LIC-0216`。
2. `GraduationScene` 第 3 页（`page == "ending"`）加一层：先画 CG，再在底部
   `480×86` 区域盖 `#1B1F2A`（alpha 0.82）暗带，标题与正文挪进暗带里
   （标题 y≈196、正文 y≈216，正文折行宽度按 460 重算）。
3. CG 缺失时退回现在的纯文字版，不报错。

## 7. 出图自查

1. 尺寸 480×270（4× 生成后最近邻缩）；
2. 底部 80 px 没有重要元素（要被暗带压住）；
3. 没有文字 / 字母 / 数字，屏幕、白板、奖牌、通知一律纯色块；
4. 只用 32 色板，硬边像素，无渐变无抗锯齿；
5. 主角造型与立绘一致：奶娃黄发浅黄上衣；李振兴深色短发深蓝上衣；符闹吃体格壮、深色上衣；奈珑浅棕短发白衬衫；
6. 情绪对得上正文（延毕=自嘲、考研=安静专注、技术=熬夜兴奋、恋爱=甜、平平无奇=平静）。
