## 2. 结局判定：谁先满足谁赢

`EndingService.evaluate()` 按 `priority` 从小到大检查，**第一个全部满足的生效**，
`ending_balanced` 无条件兜底。所以六条路线互斥靠优先级：

| 优先级 | 结局 | 硬指标 | 依赖旗标 |
| --- | --- | --- | --- |
| 1 | 学术研究 | 学业 ≥70、图书馆 ≥10 次 | `accepted_lab`（S6） |
| 2 | 社团领袖 | 社交 ≥60、社团 ≥10 次、符闹吃关系 ≥60 | `ran_for_president`（S5） |
| 3 | 独立开发者 | 兴趣 ≥60、创作 ≥8 次 | `held_exhibition`（S7） |
| 4 | 数字内容方向 | 兴趣 ≥60、打游戏 ≥10 次 | `joined_game_jam`（S7） |
| 5 | 活力生活家 | 体力 ≥55、社交 ≥40、心情 ≥70、锻炼 ≥10 次 | 无 |
| 6 | 平衡毕业生 | 无 | 无 |

> 冲突处理：想拿「社团领袖」就别把学业刷到 70 + 图书馆 10 + 课题组；
> 想拿「独立开发者」就别顺手去游戏马拉松（否则 S7 只能二选一，没问题——
> 关键是别同时凑满 10 次打游戏 + `joined_game_jam`，否则会被优先级 4 抢走。
> 独立开发者要求兴趣 60 且 `held_exhibition`，若同时 `joined_game_jam` 且打游戏 ≥10，
> 优先级 3 仍先判定，所以安全；反过来「数字内容」最怕的是顺手办了作品展。

## 3. 路线 A：学术研究（priority 1）

**一句话**：把图书馆靠窗那张桌子坐穿，最后跟着李振兴进课题组。

### 学期选择

| 学期 | 选项 | 结果原文 |
| --- | --- | --- |
| S1 | 跟李振兴参观实验室 | 实验室的仪器让奶娃挪不开眼，李振兴在旁边轻轻点头。 |
| S2 | 通宵突击复习 | 考试铃响时奶娃打了个哈欠，但成绩单还算体面。 |
| S3 | 这次先当观众 | 展台前围了一圈人。奶娃默默把这份心动记进了心里。 |
| S4 | 趁人少去自习 | 运动会的喧闹隔在窗外，自习室里格外安静。 |
| S5 | 专心做自己的事 | 奶娃把这段时间留给了自己喜欢的事，心里很踏实。 |
| S6 | 加入课题组 | 第一次组会听完，奶娃觉得自己摸到了更大世界的门把手。 |
| S7 | 去校外实习 | 实习的第一个月，课本上的知识第一次用进了真实项目。 |
| S8 | 把毕业论文改到满意 | 最后一稿交上去的那天，李振兴说了句“靠谱”。 |

### 排程（每天 3 格）

| 学期 | 第 1 天 | 第 2 天 |
| --- | --- | --- |
| S1 | 图书馆学习 ×2、食堂用餐 | 图书馆学习 ×2、宿舍休息 |
| S2 | 图书馆学习 ×2、食堂用餐 | 图书馆学习 ×2、宿舍休息 |
| S3 | 图书馆学习 ×2、食堂用餐 | 宿舍休息、校园闲逛、食堂用餐 |
| S4 | 上课 ×2、食堂用餐 | 上课、宿舍休息、食堂用餐 |
| S5 | 上课、图书馆学习、食堂用餐 | 宿舍休息、校园闲逛、食堂用餐 |
| S6–S8 | 上课 ×2、食堂用餐 | 宿舍休息、和李振兴聊天、食堂用餐 |

要点：**前 3 个学期把图书馆刷到 10 次**（4+4+2），学业在 S2 结束就够 45
（S6 选课题组的门槛），之后靠上课与学期事件堆到 70+。

### 剧情走向

九月的社团招新日，广场上三个摊位同时朝奶娃招手。符闹吃喊得最响，奈珑把同好会的
名牌藏在手心，而李振兴只是很轻地说了一句「实验室今天开放参观」。奶娃跟了她去——
仪器反光的那一瞬间，她被那种冷静的秩序感抓住了。

第一学期期末，李振兴问要不要一起过重点，奶娃说要通宵。成绩单还算体面，代价是一整个
星期的黑眼圈。第二年春天，创作征集的海报贴满公告板，奈珑希望她一起投稿，奶娃在展台
前站了很久，最后只当了观众——那时候她心里装的是另一种东西。

运动会那天全校都在操场，自习室安静得像另一个学校。换届名单贴出来时，符闹吃问她要不要
试试，她说想把时间留给自己喜欢的事。直到大三，专业课老师叫住她：「课题组还缺一名
本科生。」李振兴在门口补了一句「如果你来，我们可以搭伙做实验」——奶娃点了头。

大四她去了校外实习，第一次发现课本上的东西能落在真实项目里。毕业前夜，她把论文又改了
一遍，最后一稿交上去那天，李振兴只说了两个字：「靠谱。」

### 结局正文

> **学术研究**
> 四年里，图书馆靠窗的位置成了第二个家。错题本换了两本，课题组的门越来越熟。
> 毕业典礼上，导师宣布奶娃将留组深造。李振兴在台下轻轻鼓掌，笑得比谁都真。
> 五年后，第一篇署名论文发表。致谢栏的最后一行写着：献给窗边的座位。

毕业页额外出现的回顾：`泡图书馆 11 次`、`回宿舍休息 8 次`、`去食堂 14 次`，
以及八条「事件：选项」记录。

### 支线

李振兴 20/45/70 三段关系事件会自然触发前两段（借你一支笔 → 错题本），
第三段「窗边的位置」（他想读研）需要关系 ≥70 且学期 ≥6——多聊一次即可。

## 4. 路线 B：社团领袖（priority 2）

**一句话**：从贴海报的新人做到社长，活动室的灯替很多人亮过。

### 学期选择

| 学期 | 选项 | 结果原文 |
| --- | --- | --- |
| S1 | 跟符闹吃去社团摊位 | 符闹吃当场把报名表塞了过来，奶娃成了社团的一员。 |
| S2 | 放平心态顺其自然 | 尽力就好。走出考场时，天蓝得刚刚好。 |
| S3 | 帮奈珑完成投稿 | 截稿前夜，两个人挤在画室里补完最后的细节，奈珑的眼睛亮亮的。 |
| S4 | 去看台加油 | 奶娃的嗓门成了看台上的主力，嗓子哑了两天。 |
| S5 | 参加竞选 | 竞选演讲比想象中顺利，台下的掌声比想象中更响。 |
| S6 | 和同学做课程项目 | 课程小组一拍即合，项目书当晚就写出了初稿。 |
| S7 | 去校外实习 | 实习的第一个月，课本上的知识第一次用进了真实项目。 |
| S8 | 和朋友们办告别聚会 | 告别聚会散场时，谁都没先说出“再见”两个字。 |

### 排程

| 学期 | 第 1 天 | 第 2 天 |
| --- | --- | --- |
| S1 | 参加社团 ×2、食堂用餐 | 参加社团 ×2、宿舍休息 |
| S2 | 参加社团 ×2、食堂用餐 | 参加社团 ×2、宿舍休息 |
| S3 | 参加社团 ×2、食堂用餐 | 宿舍休息、校园闲逛、食堂用餐 |
| S4–S8 | 和符闹吃聊天、参加社团、食堂用餐 | 宿舍休息、校园闲逛、食堂用餐 |

要点：**S3 结束前把社团刷到 10 次**，社交自然越过 35（S5 竞选门槛）；
符闹吃的关系靠 10 次社团（+30）+S1（+10）+S5（+10）+ 几次聊天（每次 +6）到 60+。

### 剧情走向

社团招新那天符闹吃把报名表直接塞进奶娃手里，连「考虑一下」的余地都没留。之后两年，
她的名字开始出现在每一张排班表上：搬桌椅、贴海报、半夜去旧礼堂借钥匙。第一次期末她
没熬夜，成绩不算好看，但也不难看。创作征集时她没投稿，陪着奈珑把最后的细节补完。

运动会她没跑，站在看台上喊哑了嗓子。换届名单下来的前一周，符闹吃说「我觉得你可以试试」，
奶娃真的站上了台，掌声比想象中响。大三她去做课程项目，大四去实习——社团的事一直是
「额外那一份」，但她从没落下。毕业前夜，一群人吃了很久的饭，散场时谁都没先说「再见」。

### 结局正文

> **社团领袖**
> 四年里，从贴海报的新人到独当一面的社长，活动室的灯为很多人亮过。
> 毕业那天，社团的年度大活动如期开幕。奶娃在幕后看着一切运转，笑着退后了一步。
> 五年后，奶娃在公益组织策划一场场活动。符闹吃偶尔来串门，钥匙还挂在同一串上。

### 支线

符闹吃三段（缺人的海报 → 活动前夜 → 交接钥匙）在 20/45/70 自动触发，
这条路线正好能把三幕全开——最后一幕他把活动室、储物柜、荣誉柜的钥匙交给奶娃。

同好会的展台后面，奈珑把名牌递过来时耳根是红的。之后两年，奶娃的夜里全是提交记录，
凌晨那几次都在改同一个 bug。第一学期期末她没复习，成绩平平。第二年创作征集，
她把作品交了上去，心跳得像鼓点，奈珑在展板前站得比谁都久。

运动会她在看台上喊，换届的事她推掉了，导师邀请她也婉拒了——「时间要留给想做的事」。
大四那场个人作品展，很多人停在她的画前。毕业前夜，她把一直想做的那个作品收尾，
按下保存键的那一刻，四年的夜晚都值了。

### 结局正文

> **独立开发者**
> 四年里，IDE 的提交记录像一条长河，凌晨那几次提交都在改同一个 bug。
> 毕业作品展上，那款两个人做的小游戏被放在正中央，排队试玩的人比想象中长。
> 五年后，奶娃的工作室开在校外老街。启动画面里，署名处写着两个名字。

### 支线

奈珑三段（速写本 → 双人通关 → 同一张画布）在 20/45/70 触发，
创作与打游戏都会加她的关系（每次 +2）。

> 五年后，奶娃和奈珑的工作室上线了第三款游戏。启动画面里，奶娃朝玩家挥手。

## 7. 路线 E：活力生活家（priority 5）

**一句话**：操场的日落数都数不完，毕业照里每个人都想挤到她旁边。

### 学期选择

| 学期 | 选项 | 结果原文 |
| --- | --- | --- |
| S1 | 跟符闹吃去社团摊位 | 符闹吃当场把报名表塞了过来，奶娃成了社团的一员。 |
| S2 | 放平心态顺其自然 | 尽力就好。走出考场时，天蓝得刚刚好。 |
| S3 | 这次先当观众 | 展台前围了一圈人。奶娃默默把这份心动记进了心里。 |
| S4 | 报名长跑 | 最后一百米，全班的加油声把奶娃推过了终点线。 |
| S5 | 帮符闹吃拉票 | 奶娃跑遍每栋宿舍楼发传单，符闹吃感动得差点当场宣布结果。 |
| S6 | 婉拒，保留自由时间 | 老师笑着说没关系。奶娃把时间留给想做的事，不后悔。 |
| S7 | 去校外实习 | 实习的第一个月，课本上的知识第一次用进了真实项目。 |
| S8 | 和朋友们办告别聚会 | 告别聚会散场时，谁都没先说出“再见”两个字。 |

### 排程

| 学期 | 第 1 天 | 第 2 天 |
| --- | --- | --- |
| S1 | 操场锻炼 ×2、食堂用餐 | 操场锻炼 ×2、宿舍休息 |
| S2 | 操场锻炼 ×2、食堂用餐 | 操场锻炼 ×2、宿舍休息 |
| S3 | 操场锻炼 ×2、食堂用餐 | 宿舍休息、校园闲逛、食堂用餐 |
| S4–S7 | 参加社团 ×2、食堂用餐 | 宿舍休息、校园闲逛、食堂用餐 |
| S8 | 和符闹吃聊天、校园闲逛、食堂用餐 | 宿舍休息、校园闲逛、食堂用餐 |

要点：**锻炼 10 次**（体力 20 → 60，跨过 55），社交靠 6~7 次社团（每次 +4）+
S1/S4/S5 的社交加成到 40+，心情本来就会被锻炼（+4/次）和闲逛（+5/次）顶到 100。

### 剧情走向

这条线的四年是亮的：操场、跑鞋、傍晚的云。社团招新她跟符闹吃走了，运动会报名表上空着的
长跑那栏被她填上——最后一百米全班把她的名字喊过终点线。换届时她没参选，只是跑遍每栋
宿舍楼替符闹吃发传单，把人感动得差点当场宣布结果。

创作征集与她无关，课题组的邀请她婉拒了，大四去实习也只是顺带。她的时间几乎都花在外面：
一个又一个黄昏，一次又一次绕校园。毕业前夜的那场告别聚会，照片里挤满了人。

### 结局正文

> **活力生活家**
> 四年里，操场的日落数都数不完，心情的颜色一直是明亮的。
> 毕业那天，朋友们想合影都先找奶娃，挤在一张照片里的笑容比阳光晃眼。
> 五年后，周末徒步团的发起人名单上，奶娃的名字一直在最上面。

## 8. 路线 F：平衡毕业生（priority 6，兜底）

**一句话**：什么都沾一点，什么都没走到底——但四年顺利毕业了。

### 学期选择

任意都行，只要不凑齐上面五条里的旗标。最稳的一套：

| 学期 | 选项 |
| --- | --- |
| S1 | 跟符闹吃去社团摊位（只这一次不进社团循环，社团次数停在 2~3 次） |
| S2 | 按计划稳稳复习 |
| S3 | 这次先当观众 |
| S4 | 去看台加油 |
| S5 | 专心做自己的事 |
| S6 | 和同学做课程项目 |
| S7 | 去校外实习 |
| S8 | 和朋友们办告别聚会 |

### 排程

每天固定「一件正事 + 吃饭 + 休息/闲逛」，九个活动轮流摸一遍，每个计数器都停在
2~5 次之间：

| 学期 | 第 1 天 | 第 2 天 |
| --- | --- | --- |
| S1 | 上课、食堂用餐、图书馆学习 | 宿舍休息、校园闲逛、食堂用餐 |
| S2 | 上课、食堂用餐、打游戏 | 宿舍休息、校园闲逛、食堂用餐 |
| S3 | 创作、食堂用餐、参加社团 | 宿舍休息、校园闲逛、食堂用餐 |
| S4 | 上课、食堂用餐、操场锻炼 | 宿舍休息、校园闲逛、食堂用餐 |
| S5 | 图书馆学习、食堂用餐、打游戏 | 宿舍休息、校园闲逛、食堂用餐 |
| S6 | 创作、食堂用餐、参加社团 | 宿舍休息、校园闲逛、食堂用餐 |
| S7 | 上课、食堂用餐、操场锻炼 | 宿舍休息、校园闲逛、食堂用餐 |
| S8 | 上课、食堂用餐、打游戏 | 宿舍休息、校园闲逛、食堂用餐 |

### 剧情走向

没有一件事被做到极端。学业稳步往前，图书馆去过几次但没住下；社团报过名，活动去过
两三回；同好会的游戏玩过，没熬到通关；操场去过，也没报名任何项目。学期事件选的都是
最中庸的那一项：稳稳复习、当观众、看台加油、专心自己的事、课程项目、校外实习、
告别聚会。

四年就像很多人的四年：没什么可写进校史，但也没留下遗憾。

### 结局正文

> **平衡毕业生**
> 四年里没有走极端：学业稳步，朋友在侧，喜欢的事一件没落下。
> 毕业那天，奶娃把回忆一件件打包，行李箱恰好装得下。
> 五年后的某个黄昏，奶娃路过一所大学，忽然想起：那年夏天，一切才开始。

毕业回顾页若一条都比不出来，会显示：
「这四年过得波澜不惊，但每一天都算数。」

## 11. 常见翻车点

1. **低心情折学业**：心情 <30 时上课 / 图书馆的学业减半——冲学业 70 时别连续熬夜，
   中间插一次「宿舍休息 +3」「食堂 +4」「闲逛 +5」。
2. **熬夜旗标**：一天打第 3 次游戏会挂 `stayed_up_late`，次日只回 20 精力，
   连续两天基本就把这一学期废了。
3. **S5 竞选锁死**：需要 `club_member`（社团 ≥3 次或 S1 选社团摊位）且社交 ≥35；
   如果 S1 选了别的摊位，就得老老实实刷 3 次社团。
4. **S6 课题组锁死**：学业 ≥45。10 次图书馆（+50）足够，但低心情折半后可能差几点。
5. **S3 / S7 的创作门槛**：S3 提交要创作 ≥2 次，S7 办展要 ≥4 次；S7 马拉松要打游戏 ≥4 次。
6. **优先级抢结局**：同时满足多条时按 1→6 取最高，想拿低优先级的那条就别把高优先级的
   条件全凑齐（尤其「兴趣 60 + 创作 8 + 作品展」会稳定压过「数字内容方向」）。
7. **最后一天的毕业**：第 16 天结算后还要先结算 S8 事件才会毕业，S8 的选择会算进最终属性，
   记得按目标结局选（论文 / 聚会 / 作品）。
