# 室内家具与装修 · AI 生图提示词（5 栋建筑 · 正面图版）

> 家具和墙上装饰一律画**正面图（front elevation）**，不画 3/4 斜视、不画俯视。
> 依据：游戏里的树、路灯、垃圾桶、建筑全部是"立在地上的一张正面卡"
> （`game/world/campus_scene.py::make_prop_card`，卡片按 −40° 俯仰正对相机），
> 家具沿用同一套规则，整间房才不会出现两种透视打架。
> 只有**地板**是正俯视四方连续贴图。
>
> 落位与校验由 `tools/import_interior_art.py`（待写）完成；规格见 §5。

---

## 0. 全局规格

| 项 | 规定 |
| --- | --- |
| 像素密度 | **24 px = 1 米**（和室外场景一致） |
| 视角 | **正面平视**：正交、无透视、不画顶面、不画斜侧；只表达"站在地上从正面看到的样子" |
| 画布比例 | **宽 : 高 = 占地宽度 : 实物高度**（游戏按这个比例算卡片宽度，比例错了会被拉伸） |
| 底边 | 物体**底边贴齐画布底部**，左右居中，画布外全透明 |
| 调色板 | 只用 `assets/palette.png` 的 32 色 |
| 描边 | 不描边（描边只给角色/NPC），靠 3 级明暗分层 |
| 光影 | 光源在**左上方**，右下侧压暗；不画地面阴影 |
| 背景 | 全透明 RGBA，透明像素 RGB 必须为 0（不要白底、不要棋盘格） |
| 生成方式 | 先按 4× 尺寸生成（如 96×44 → 384×176），再最近邻缩到目标尺寸 |
| 文字 | 画面里不许出现任何文字/字母/数字 |

## 5. 交付与落位

| 类别 | 数量 | 命名 | 尺寸 |
| --- | --- | --- | --- |
| 地板 | 5 | `assets/interior/<building>/floor.png` | 64×64 无缝 |
| 墙面 | 5 | `assets/interior/<building>/wall.png` | 64×72 无缝 |
| 家具 | 17 | `assets/interior/<building>/furn_<id>.png` | 见 §4 |

`<building>`：`dorm / classroom / library / clubroom / canteen`；`<id>` 取 `map.json` 的 `furniture[].id` 去掉 `furn_` 前缀。

**为什么画布比例必须对**：渲染用 `make_prop_card(rect, texture, height)`，
卡片宽度 = `height × 画布宽/高`。画布比例等于「占地宽 : 实物高」时，卡片正好
占满占地宽度、高度等于实物高度；比例偏了要么被拉扁、要么左右缩水。

**交付前自查**

1. 四角 alpha = 0，没有白底/棋盘格残留；
2. 颜色 ≤ 32 且都在 §0.1 色板内；
3. 画布尺寸与 §4 完全一致，物体底边贴齐画布底部；
4. 是正面平视——**没有顶面、没有侧面**；地板除外（它是正俯视）；
5. 画面里没有任何可读文字；
6. 文件名全小写、与表一致。
