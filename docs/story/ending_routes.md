# 新剧情路线说明

本版本采用五个结局，优先级从 1 到 5。当前初始属性为学业 10、体力 20、社交 10、兴趣 10；每局 16 天、每天 3 次行动，共 48 次行动。

## 结局判定

| 优先级 | ID | 名称 | 条件 |
|---|---|---|---|
| 1 | ending_delayed | 延毕结局 | 学业 < 40 |
| 2 | ending_kaoyan | 考研结局 | 学业 ≥ 75、图书馆 ≥ 10、李振兴关系 ≥ 60、kaoyan_partner |
| 3 | ending_tech_master | 技术大牛 | 学业 ≥ 40、社交 ≥ 55、社团 ≥ 10、符闹吃关系 ≥ 65、tech_project |
| 4 | ending_romance_nailong | 坠入爱河 | 学业 ≥ 40、兴趣 ≥ 55、奈珑关系 ≥ 80、创作+打游戏 ≥ 10、confessed_nailong |
| 5 | ending_mediocre | 平平无奇 | 其余正常毕业状态 |

学业红线在 S8 事件结算后检查。学业低于 40 时，毕业界面显示教务处学分预警剧情。

## 学期节点

| 学期 | 关键选项 |
|---|---|
| S1 | 社团摊位、实验室、同好会三选一 |
| S2 | 通宵复习、按计划复习、放松 |
| S3 | 图书馆整理文献、排查社团服务器、帮助奈珑投稿 |
| S4 | 刷真题、搭建活动网络、陪奈珑聊天 |
| S5 | 启动技术项目、整理考研书单、专心做自己的事 |
| S6 | 结成考研搭子、继续技术项目、陪奈珑 |
| S7 | Game Jam 后表白、考研冲刺、技术交接、普通实习 |
| S8 | 论文答辩、告别聚会、完成个人作品 |

## 固定课堂演示路线

### 考研

行动计数：图书馆 12、交谈李振兴 5、上课 4、食堂 12、休息 10、闲逛 5。

事件顺序：S1 实验室 → S2 按计划复习 → S3 图书馆 → S4 真题 → S5 考研书单 → S6 考研搭子 → S7 最后冲刺 → S8 论文答辩。

### 技术大牛

行动计数：社团 12、交谈符闹吃 5、上课 7、食堂 12、休息 7、闲逛 5。

事件顺序：S1 社团 → S2 按计划复习 → S3 服务器 → S4 活动网络 → S5 技术项目 → S6 继续项目 → S7 技术交接 → S8 论文答辩。

### 坠入爱河

行动计数：创作 6、打游戏 6、交谈奈珑 6、上课 7、食堂 10、休息 7、闲逛 6。

事件顺序：S1 同好会 → S2 按计划复习 → S3 投稿 → S4 看台聊天 → S5 专心做自己的事 → S6 陪奈珑 → S7 表白 → S8 论文答辩。

### 延毕

行动计数：打游戏 16、食堂 8、休息 16、闲逛 8。

闲逛限制为 8 次，避免随机学业事件影响演示结果。S8 选择论文答辩后，学业仍低于 40，进入延毕结局。

### 平平无奇

行动计数：上课 8、食堂 8、社团 8、锻炼 8、打游戏 8、休息 8。

事件选择不完成考研搭子、技术项目或表白旗标，最终进入普通毕业结局。

## 规则实现

- 关系 ID 保持 npc_chenlang、npc_sumo、npc_xiaoyou，显示名分别为李振兴、符闹吃、奈珑。
- “创作 + 打游戏 ≥ 10”使用 counter_sum 条件。
- 规则唯一来源是 game/systems/spec_data.py，JSON 由 python -m game.systems.spec_export 导出。
- 存档版本提升为 2；旧版本存档不用于本剧情版本的课堂演示。
