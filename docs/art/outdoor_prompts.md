# 操场 / 中心广场 · AI 生图提示词（室外地面 + 立牌道具）

> 现状：这两块地方现在只是**一块纯色地面片 + 一个交互点**——
> 操场是棕色方块（`AREA_COLORS["loc_playground"]`），中心广场是浅灰方块。
> 树、路灯、垃圾桶、告示牌已经有了立牌图，唯独场地本身和场地设施是空的。
>
> 这份文档给的是**可以直接粘贴给生图模型**的提示词，按"地面贴图"和"立牌道具"两类分开，
> 每件都算好了画布像素，生成后丢进 `素材/室外/` 我就能接。

## 0. 全局规格

| 项 | 规定 |
| --- | --- |
| 像素密度 | **24 px = 1 米**（和室内家具、树、路灯同一套） |
| 输出格式 | **带 alpha 的 PNG**（不要 jfif/jpg） |
| 立牌视角 | **按进深分三档**（见 §0.2）：高瘦件正面 + 20°，低矮面状件俯视为主 |
| 地面视角 | **正俯视**（top-down），因为地面是水平面片 |
| 画布 | 立牌：宽 = 占地宽 × 24，高 =（实物高 + k × 进深）× 24（k 见 §0.2）；地面：见 §2.1 / §3.1 |
| 底边 | 立牌物体底边贴齐画布底部，左右居中，四周全透明 |
| 调色板 | 只用 `assets/palette.png` 的 32 色 |
| 描边 | **不描边**（描边只给角色），靠 3 级明暗分层 |
| 光影 | 光源在**左上方**；顶面比正面亮一档，正面右下压暗 |
| 文字 | 画面里不许出现任何文字 / 字母 / 数字（记分牌、公告栏都留空板面） |
| 投影 | **不要画地面投影**（游戏里由地面自己表达光照，画上去会变成一块灰斑） |
| 生成方式 | 先按 4× 画布生成，再**最近邻**缩到目标像素 |

### 0.2 视角分档（重要）

能不能看清顶面，取决于**进深**而不是"统一 20°"。看台、喷泉、花坛这类又矮又深的东西，
在 40° 俯视的镜头里**主要看到的是顶面**，只画一条薄顶面会变成一堵矮墙；反过来，
石碑、旗杆这种薄片件画成俯视就没法看了。所以分三档：

| 档 | 判据 | 顶面占比 k | 画布高 | 本批适用 |
| --- | --- | --- | --- | --- |
| **A 高瘦** | 高 ≥ 1.5 m 且 进深 ≤ 0.6 m | 0.34（≈20°） | 高 + 0.34×进深 | 足球门、篮球架、栏架、记分牌、石碑、公告亭、旗杆 |
| **B 中等** | 高 ≥ 进深，进深 0.6~1.2 m | 0.65（≈40°） | 高 + 0.65×进深 | 操场长椅、广场长椅 |
| **C 低矮面状** | 进深 > 高 | 0.95（≈55°，俯视为主） | 高 + 0.95×进深 | **看台、喷泉、花坛** |

- A 档：正面为主、只露一条薄顶面，**看不到侧面**；
- B 档：正面 + 40° 俯角，座板/踏面能看全，侧面仍不画；
- C 档：**俯视为主**，顶面占画面大部分，正面只剩底部一条挡墙/池壁，
  这个角度才不会把平台画成墙。

> 为什么 C 档要 0.95：镜头俯角实际约 40°，一块深 d 的地面在画面上的高度 ≈ 0.77×d，
> 而竖直高度只占 0.65×h。进深越大，顶面就越"压扁不了"——看台 2 m 进深、
> 1.6 m 高，顶面在画面里比正面还高一截，正是真实看到的样子。

## 4. 交付与落位

**放哪**：全部丢进 `奶娃/素材/室外/`，文件名照上表的第 五 列，**PNG 带 alpha**。

**我怎么接**（图到了我来做，不用你管）：

1. 道具：照 `tools/import_campus_props.py` 的流程（去白底/去投影 → 裁到物体 → 缩到画布），
   新增 `tools/import_outdoor_props.py` 写进 `assets/campus/textures/props/`，
   登记 manifest `campus_texture_prop_<名字>`，并在
   `game/core/world_scene.py::CampusSceneAdapter.PROP_ART` 里加前缀映射
   （`("prop_goal", "campus_texture_prop_goal", 2.16)` 这种，第三个值是"画布高 ÷ 24"）。
2. 场地道具要在 `content/world/map.json` 的 `props` 里加条目（id + 占地矩形），
   占地宽 = 上表的"尺寸（米）"第一列，`make_prop_card` 会按画布比例把卡片还原成这个宽度。
3. 地面：`areas` 现在只吃纯色（`AREA_COLORS`），接入时要给
   `campus_scene` 加一张 `AREA_TEXTURES = {"loc_playground": (tex, tile_m|None)}`，
   平铺的走 `make_ground(..., texture=..., tile_m=4.0)`，整块走 `tile_m=None` 直接铺满。
   这一步我在接入时一起改，图先按 §2.1 / §3.1 的尺寸出就行。

## 5. 出图自查

1. 透明背景：四个角 alpha = 0，**没有**棋盘格 / 白底 / 灰底；
2. 没有描边、没有抗锯齿、没有渐变（放大看是硬像素块）；
3. 颜色数 ≤ 32，且都在 §0.1 色板里；
