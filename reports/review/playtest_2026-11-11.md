## 二、P0

### QA-01 毕业界面「四年回顾」把内部 ID 直接印给玩家

![毕业回顾](playtest_shots/41_graduation_p2.png)

**现象**：毕业第 2 页只有一行 `#sem_1_club_fair:fair_club`；完整跑完一局还会出现
`#class_count×3`、`#exercise_count×1`（控制台同时刷 `缺失 text_id: class_count×3`）。

**根因**：`game/systems/ending_service.py:33-37` 的 `_highlights()` 生成的是
`f"{name}×{count}"`（计数器键名）和 `state.event_log` 里的 `"<event_id>:<choice_id>"`，
它们**不是 text_id**；而 `game/ui/graduation_scene.py:80-85` 用
`text_db.get_raw(tid)` 逐条渲染，查不到就回落成 `#<原文>`。

**建议**：两条路选一条，别在 UI 里猜——
1. 数据侧：`highlights` 改产出 text_id，例如
   `ending.count.<counter>` = "上了 {n} 节课"、`evt.<id>.choice.<choice>.review`；
2. 或 UI 侧：把 `highlights` 当结构化数据（`(kind, key, value)`）由 D 负责拼文案。
**验收**：任意一局通关后，回顾页不出现 `#`、不出现下划线英文键名。

### QA-02 和 NPC 聊天没有任何界面反馈（提示文案还写错了）

![NPC 提示](playtest_shots/54_npc_prompt.png)
![聊天后](playtest_shots/55_npc_after_e.png)

**现象**：站在符闹吃面前，提示框写的是
「[E] 符闹吃点头致意，又埋回了习题里。」（一句**已经聊完**的叙述），
按 E 之后**屏幕上什么都不发生**：没有对话框、没有结果面板、没有飘字；
唯一的反馈是行动点少一个、提示框变灰成「今天已经聊过了，明天再来吧」。
Human 本人 19:16 的实机日志也是同一个结果：
`[WORLD] E ia_npc_xiaoyou -> npc` 之后紧跟着就是离开建筑，中间没有任何 push。

**根因**（两处叠加）：
1. `game/core/world_scene.py:361-377` `_on_interact()` 只处理
   `result.kind == "activity"` 和 `"blocked"`；`"npc"` 分支**没有**任何 UI 动作。
   而 `ResultPanel` 里明明已经写好了交谈的专门分支
   （`game/ui/result_panel.py:20-24, 96-101`，`talk.npc_xxx` → 标题=`npc.*.name`、
   正文=`npc.*.talk`、无插图色块）——**这段代码从来没被调用过**。
2. 提示文案用错了键：`game/world/interaction_service.py:76`
   取 `npc.{short}.talk`，而 `content/text/zh_CN/strings.json:48`
   的 `npc.sumo.talk` 是"聊完之后的叙述句"。提示框应显示动作名（「和符闹吃聊天」）。

**建议**：
- `_on_interact` 里把 `"npc"` 与 `"activity"` 合并处理：
  `flow.handle_activity_result(result.payload)` + `scenes.push("ResultPanel", result=result.payload)`
  （交谈返回的就是 `ActivityResult(activity_id="talk.npc_xxx")`，UI 已支持）；
- 顺手补 `ui.prompt.talk` = "和{name}聊天"，prompt 走这个键，`npc.*.talk` 留给结果面板；
- 回归测试：按 E 后必须 push ResultPanel，且面板标题=角色名、正文=`npc.*.talk`。

## 三、P1

### QA-03 查看点（inspect）长文本不换行，直接冲出对话框

![查看点](playtest_shots/36_inspect_page.png)

**现象**：校门告示牌的文字「告示牌上贴满了海报：讲座、招新、比赛。每次路过，纸的颜色都不大…」
只画一行，**超出对话框右边缘并顶到屏幕外**。

**根因**：`game/core/world_scene.py:754-757`（`EventSceneAdapter.apply` 的 `text_id` 分支）
把整段文本塞进 `dialogue.show_page({"lines": [整段]})`；
`DialogueBox` 的 `MultilineLabel` 只按 `lines` 逐行画，**不做自动折行**
（正常剧情页靠 `dialogues.json` 里人工分好行，所以平时看不出来）。

**建议**：给 `MultilineLabel` 加按宽度折行的工具（`theme.wrap_prompt_details` 已有类似实现），
在 `show_page` 里对超过 `dialogue_body` 宽度的行自动折；或数据侧把 inspect 文本拆成多行。
**验收**：任意 inspect 文本都在 `dialogue_body`（108,188,362,72）内、最多 4 行。

### QA-04 结果面板：正文和数值变化画在同一行上，字压字

![结果面板](playtest_shots/06_result_panel.png)

**现象**：「跑完五圈，浑身舒畅，晚风正好。」的末尾直接压在「精力 -18」上，
两段文字重叠，读起来是乱码块。

**根因**：`game/ui/result_panel.py:44` 正文 `y+110` 起、最多 2 行（`LINE_HEIGHT` 16 → 到 `y+142`）；
`game/ui/result_panel.py:122-126` 数值从 `y+118` 起、`x+168` 开始，
**在正文第一行的行高范围内**，且正文没有右边距限制。

**建议**：数值起点改到正文下沿之后（如 `y + 110 + 2*LINE_HEIGHT + 6`），
并把正文折到 `x+8 … x+160` 宽度内；或数值改成正文下方的两列网格。

### QA-05 暂停菜单标题写成「状态面板」

![暂停菜单](playtest_shots/10_pause_menu.png)

`game/ui/pause_menu.py:35` 用了 `text_db.get("ui.tab.title")`（= 状态面板），
且没有底部按键提示（其他菜单都有）。建议新增 `ui.menu.pause_title`（"菜单"/"暂停"），
并补一行 `[Esc] 返回`。

### QA-06 日结算标题天数 +1：「第 2 天结束」其实是第 1 天

![日结算](playtest_shots/16_day_summary.png)

**根因**：`game/core/flow.py:425-436` 先 `calendar.end_day(state)`（day_index 0→1），
再 `scenes.push("DaySummary")`；`game/core/world_scene.py:846-849`
用 `day = state.day`（已经是 2）。
**建议**：adapter 里传 `state.day - 1`（并用 `max(1, …)` 兜底），最后一天也就不会出现"第 17 天"。

### QA-07 室内：角色被家具/墙体挡住，站在门口基本看不见自己

![进入教室](playtest_shots/51_classroom_enter.png)
![课桌前](playtest_shots/52_classroom_desk_prompt.png)

**现象**：从教室门口进去（出生点 8,1.6），角色几乎完全被"课桌排"的方块盖住，只露出头顶；
走到讲台前又变成"站在桌子上"。整间教室是白模：灰墙 + 三块棕色方块，没有任何贴图。
走廊/房间外的区域直接是清屏色，画面像"浮在虚空里的一个盒子"。

**根因**：角色是 2.5D 立牌（`make_character_card`，P=40 向后仰），
家具是**有高度的 3D 长方体**且开着深度测试，两者没有统一的 y 排序/绘制优先级；
立牌上半身在深度上落到家具后面，就被切掉了。室内家具本身也没有接入 `prop_art`（无贴图）。

**建议**：
1. 角色卡片关深度测试并放到固定高 bin（`setBin("fixed", …)` + `setDepthTest(False)`），
   或按 y 值给所有"N 米以上"物件做排序（经典 2.5D 做法）；
2. 室内加地板/墙纸无缝贴图，家具换成像素立牌（`docs/art/interior_prompts.md` 里已经有 17 件家具提示词）。

### QA-08 离屏截图工具截不到 UI，不能当验收证据

`python -m game --dev --scene CampusScene --offscreen --frames 10 --screenshot x.png`
产出的是 **480×270 的纯 3D 缓冲**，HUD、对话框、菜单**全部没有**
（`reports/standalone/A/offscreen.png` 就是一张纯色 `#252A3A`）。

**根因**：`game/core/render_pipeline.py:save_buffer_screenshot()` 优先取 `self.buffer`
（低分辨率场景缓冲），UI 画在 `aspect2d`（主窗口），根本不在那张纹理里；
只有 buffer 取不到时才回落 `app.win`。

**影响**：所有"用 README 里的截图命令取证"的人都拿不到 UI 画面，等于验收不了 UI。
**建议**：新增 `--screenshot-ui`（直接 `app.win.getScreenshot()`），或默认改成取窗口再缩到 480×270。
