| 资产类型 | 画布 | 锚点 / 裁切 | 说明 |

### 0.3 生成 → 落位五步（每张图都按这个走）

1. **按 4 倍画布生成**（例如立牌 48×48 → 出 192×192；头像 96×96 → 384×384；行走表 384×384 → 1536×1536）。
2. **抠图**：背景要纯色（透明 PNG 最好；若模型只给白底/灰底，用工具按背景色泛洪去背）。
   **绝对不要让模型画棋盘格**——上一批家具图把棋盘格画进画面，抠了三轮。
3. **整数降采样**：`tools/pixel_downscale.py::integer_downscale()`（按 N×N 块取中位色），
   1 美术像素 → 1 游戏像素；这一步比"再像素化一次"干净得多。
4. **量化**：角色/道具 32 色、CG 64 色，关掉抖动；透明像素 RGB 归 0。
5. **登记**：`assets/manifest.json` 加条目（`id / type / path / license_id`，
   角色表另加 `frame_w/frame_h/cols/rows/pivot`），`assets/LICENSES.csv` 补一行，
   然后跑 `pytest tests -k "asset or npc or portrait"` 与 `python -m game --dev --offscreen --frames 40 --echo`
   看日志里有没有 `[ASSET] missing`。

### 1.1 角色立牌（场景内 48×48）

**中文前缀**

```
像素风游戏角色立牌，正面平视、正对镜头（no perspective, front view），
2.5D 卡片式素材：只有正面，不画侧面、不画背面、不画地面投影。
24 像素 = 1 米，人物身高约 38 像素，双脚并拢站在画布底部中间。
硬边像素、无抗锯齿、无渐变、无描边；只用给定 32 色调色板；
光源在左上方，正面右侧下压半档；背景全透明，画面里没有任何文字。
```

**English prefix**

```
pixel art character standee for a 2.5D game, straight front view facing the camera,
no perspective, front only — no side faces, no back view, no baked ground shadow.
24 pixels per meter, character about 38 px tall, both feet together on the bottom-center.
Hard-edged pixels, no anti-aliasing, no gradients, no outlines; 32-color palette only;
light from upper-left, front right side half a step darker; transparent background, no text.
```

### 1.2 角色半身立绘（头像 / 争论 96×96）

```
像素风游戏角色半身立绘（bust portrait），胸前裁切，正面略 3/4 侧，
正方形构图，人物居中、头顶留一点空；
硬边像素、无抗锯齿、无渐变，只用 32 色调色板；
背景是纯灰色 #808080 平涂（不是棋盘格、不是白色），画面里没有任何文字。
```

### 1.3 方向行走表（384×384，8 列 × 8 行）

```
像素风游戏角色行走序列帧表（walk cycle sprite sheet），8 列 × 8 行，单帧 48×48，整表 384×384。
行序从上到下固定为：面向镜头(S)、朝右下(SE)、朝右(E)、朝右上(NE)、背对镜头(N)、朝左上(NW)、朝左(W)、朝左下(SW)。
每行 8 帧循环：第 1 帧与第 8 帧姿态接近但不完全相同，中间 6 帧做完整换步。
角色身高 38 像素、脚底固定在每帧底部中间（脚点 24,46），帧与帧之间不要缩放、不要位移漂移。
硬边像素、无抗锯齿、无渐变、无描边；只用 32 色调色板；背景全透明；画面里没有任何文字或网格线。
```

> 8 个方向**必须是同一角色同一套配色**；先出 1 张 4×4 的方向草图对齐，再扩到 8×8。
